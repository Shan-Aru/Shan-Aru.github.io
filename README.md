# Shandhiya Chhetri — Portfolio

My personal portfolio: experience, projects, skills and contact details.

**Live:** https://shan-aru.github.io

## Structure

```
.
├── index.html          # Page content
├── css/
│   └── style.css       # Design tokens, layout, light and dark themes
├── js/
│   └── main.js         # Theme toggle, mobile menu, active nav link, scroll reveal, copy email
└── assets/
    └── favicon.svg
```

Plain HTML, CSS and JavaScript. No build step and no dependencies apart from Google Fonts.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

then visit http://localhost:8000.

## Deploy

GitHub Pages serves the `main` branch of this repository. Commit and push, and the site updates within a minute or two.
